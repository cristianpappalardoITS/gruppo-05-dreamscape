# 004 · Frontend in HTML, CSS e JavaScript senza framework

- **Data:** 2026-10-26
- **Stato:** sostituita da [005](005-frontend-componenti-react.md)
- **Referenti:** WMD (Gaia)
- **Task:** riunione di avvio del 26/10

## Contesto
Alla riunione di avvio WMD doveva scegliere tra React oppure HTML, CSS (o SCSS) e JavaScript (o TypeScript).

## Opzioni valutate
1. React: pro: componenti riusabili / contro: uno strumento in più da imparare.
2. HTML, CSS e JavaScript senza framework: pro: niente da installare, pagine semplici / contro: i pezzi che si ripetono (la carta) vanno scritti a mano.

## Decisione
Pagine HTML, CSS e JavaScript, **senza framework**.

## Motivazione
Partire subito, senza strumenti da imparare.

## Conseguenze
Il 2/11 il gruppo ha deciso di usare React per i componenti: vedi [005](005-frontend-componenti-react.md). Le pagine restano HTML.
